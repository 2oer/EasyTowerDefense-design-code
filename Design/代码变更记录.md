### 二、代码首迭代(M1 第一刀)

新增纯 C# 逻辑切片,不含 `UnityEngine` 依赖,可在 `dotnet` 下直接跑:

| 层 | 文件 | 内容 |
|---|---|---|
| Core | `Assets/Scripts/Core/Math/Vec2.cs`、`MathUtil.cs`、`Rng.cs`、`EntityId.cs` | 二维向量、角度/钳制工具、xorshift128+ 种子随机、代际 id |
| Model | `Assets/Scripts/Model/Enums.cs`、`Defs.cs`、`ModelDatabase.cs`、`ModelValidator.cs` | 护甲/伤害/交付枚举、塔/敌/难度/地图/波次规则 POCO、启动期硬校验 |
| Combat | `DamagePacket.cs`、`ArmorTable.cs`、`DamageCalculator.cs`、`PenetrationResolver.cs` | 护甲系数 120/100/50/0、爆炸/属性衰减、易伤 ×1.5、留存贯穿 |
| Targeting | `ITargetCandidate.cs`、`TargetSelector.cs` | 权重 = 伤害系数 × 最大生命 ÷ 边缘距离;扫射按剩余血量折扣;并列按生命降序→id 升序 |
| Entity | `EnemyRuntime.cs`、`TowerAgent.cs`、`TurretMotor.cs`、`HitscanResolver.cs`、`EntityWorld.cs` | 移动/阻滞/近战;转向 + 容差;hitscan 直线(机枪)与矩形(激光);实体容器 |
| Battle | `BattleSimulation.cs`、`Wave/WaveDirector.cs`、`Economy/EconomySystem.cs` | 30 Hz 主循环「波次→开火→移动/攻基→击杀结算」;4 档释放与提前解锁;赏金/局外货币;状态哈希 |
| 数据 | `Assets/StreamingAssets/Defs/towers.json`、`enemies.json`、`difficulties.json`、`maps.json`、`waves.json` | 全部数值来自配置表;2 塔、13 敌、3 难度、1 地图、波次公式参数 |
| 工具 | `Tools/SimHarness/Program.cs`、`JsonModelLoader.cs` | 加载 + 校验 + 跑波 + 自检 + 两次同种子哈希比对 |

工程:`TowerDefense.sln`(6 个 `netstandard2.1` 类库 + 1 个 `net9.0` 控制台,库层 `LangVersion 9.0` 以兼容 Unity 2022)。

### 三、测试结果

- `dotnet build TowerDefense.sln`:**0 警告 / 0 错误**。
- `--selftest`:**12/12 PASS**(护甲 120/50/0/碎甲 20、留存 5 对衰减 2 贯穿 3 次、留存 2 贯穿 1 次、熔炉吃低级穿甲 0、实弹易伤 1.8×)。
- `--waves 9 --seed 999`:**cleared**,732 杀 / 0 漏 / 金币 1304 / 基地满血,状态哈希 `0x15FF9D714275F38B`,两次运行一致。
- `--waves 30 --seed 12345`:**第 10 波基地被摧毁**(905+ 杀后,首个大型 `铸造母体` 为重型护甲,低级穿甲伤害系数 0),状态哈希 `0x60CE083E178CD708`,两次运行一致。该结果是设计门槛而非缺陷:第 10 波前必须换中/高级穿甲武器。
- 性能:30 波约 3.8 万逻辑帧,单次运行在秒级完成。

### 四、已知边界(M2 再做)

- 只实现机枪(扫射/hitscan 直线)与激光(集中/hitscan 矩形);火箭、迫击炮、电弧、无人机、战略武器未接入。
- 敌人只实现移动/阻滞/近战;中型光环、大型投放/电磁干扰/强攻、复合分裂、射击子机远程未实现。
- 升级、三选一奖励、局外存档、表现层未接入。
