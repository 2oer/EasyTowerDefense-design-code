### 三、测试结果

- `dotnet build TowerDefense.sln`:**0 警告 / 0 错误**。
- `--selftest`:**12/12 PASS**(护甲 120/50/0/碎甲 20、留存 5 对衰减 2 贯穿 3 次、留存 2 贯穿 1 次、熔炉吃低级穿甲 0、实弹易伤 1.8×)。
- `--waves 9 --seed 999`:**cleared**,732 杀 / 0 漏 / 金币 1304 / 基地满血,状态哈希 `0x15FF9D714275F38B`,两次运行一致。
- `--waves 30 --seed 12345`:**第 10 波基地被摧毁**(905+ 杀后,首个大型 `铸造母体` 为重型护甲,低级穿甲伤害系数 0),状态哈希 `0x60CE083E178CD708`,两次运行一致。该结果是设计门槛而非缺陷:第 10 波前必须换中/高级穿甲武器。
- 性能:30 波约 3.8 万逻辑帧,单次运行在秒级完成。

### 四、已知边界(M2 再做)

- 只实现机枪(扫射/hitscan 直线)与激光(集中/hitscan 矩形);火箭、迫击炮、电弧、无人机、战略武器未接入。
- 敌人只实现移动/阻滞/近战;中型光环、大型投放/电磁干扰/强攻、复合分裂、射击子机远程未实现。
- 升级、三选一奖励、局外存档、表现层未接入。

### 五、复现命令

```bash
dotnet build TowerDefense.sln
dotnet run --project Tools/SimHarness -c Release -- --selftest
dotnet run --project Tools/SimHarness -c Release -- --waves 9 --seed 999
```

### 三、测试结果

- `dotnet build TowerDefense.sln -c Release`:**0 警告 / 0 错误**。
- `--selftest`:**22/22 PASS**。新增断言:升级链存在;电磁反器材 伤害 57.6 / 射速 1.8 / 弹匣 10 / 换弹 0.54 / 射程 33.75 / 留存 10 / 高级穿甲 / 集中策略;Lv2+Lv3+Lv4 费用 = **1625**。
- `--waves 30 --seed 12345`:
  - 第 10 波开始前买入 `mg_lv4_antimateriel`(-1125g);第 **10 / 15 / 20** 波大型波**全部清场且基地满血**(第 10 波 222 杀、第 15 波 299 杀、第 20 波 377 杀)。
  - 第 13 波补上第二座电磁反器材;第 21 波出现 3 次漏怪(中型近战),第 22 波基地被摧毁。
  - 状态哈希 `0x77A4B10C925BF440`,两次运行一致。
  - 对比第 1 次迭代:第 10 波从「基地被平推」变为「满血清场」,大型敌人首次被有效击杀。
- `--waves 9 --seed 999`:**cleared**,880 杀 / 0 漏 / 金币 1140,哈希 `0x7B95723CCADEEE60`,两次一致。
- 观察:第 13 波清场耗时约 300 s(4 座塔的输出上限 + 阻滞反向推怪造成长尾),不是死锁;已把 harness 默认关卡超时放宽到 900 s。

### 四、已知边界

- 升级只接入机枪线(Lv2–Lv4);激光尚无升级节点,转轮机枪节点已落表但未被模拟策略选用。

- 中型光环、大型投放/干扰、复合分裂、三选一奖励仍未实现。
