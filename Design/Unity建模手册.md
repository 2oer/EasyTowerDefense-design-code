# Unity 建模手册（防御塔 / 投射物 / 敌人）

> 适用版本：**v0.01early**（六塔全升级树、144 个升级节点）
> 适用对象：给本工程制作 3D 模型的美术 / 建模同学，以及负责把资源接进 Unity 的开发者。
> 关联文档：`Design/Unity接入说明.md`（工程落地）、`Design/代码架构设计.md`（逻辑分层）、`Design/thought.md`（数值与塔设计）。

本手册只讲**表现层**。模型不参与伤害、索敌、碰撞与波次结算，所有数值都来自 `Assets/StreamingAssets/Defs/*.json`。

**第一次接触建模？请先读第 2、3 节**（环境、工具、Blender 够用操作），再回到第 1 节看本工程的坐标约定。

## 0. 先看结论：10 条硬约定

| # | 约定 | 违反后的后果 |
| --- | --- | --- |
| 1 | **1 逻辑单位 = 1 米**，模型按真实米制建模 | 塔巨大或小到看不见 |
| 2 | 防御塔**根节点在炮塔底座中心、贴地 y=0** | 塔悬空或陷进地面 |
| 3 | 炮塔与投射物的**正前方 = Unity 的 +Z** | 炮管反向、导弹倒着飞 |
| 4 | 敌人的**模型主体必须能被直径 1 的单位球包住**，轴心在几何中心 | 缩放后巨大 / 下沉 / 偏移 |
| 5 | 投射物**轴心在几何中心**，同样以 +Z 为前向 | 尾迹、朝向、旋转错位 |
| 6 | **不要给模型加 Collider** | 挡住空位点击、射线拾取异常 |
| 7 | **材质必须用 Unlit（无光照）** | 场景没有灯光，Standard 材质会全黑 |
| 8 | 不在模型里放会移动根节点的脚本 / Animator | 位置每帧被逻辑层覆盖，动画失效 |
| 9 | 不要把炮塔旋转、敌人缩放写进动画 | `TowerView` / `EnemyView` 每帧覆盖这些 Transform |
| 10 | 新资源通过 **AssetCatalog** 挂接，不直接改逻辑层 | 失去占位回退，换资源要改代码 |

## 1. 坐标、单位与朝向

### 1.1 世界与逻辑的换算

- 逻辑坐标 `(x, y)` → 世界坐标 `(x, 0, y)`，默认 `unitScale = 1`。
- 地图 **64 × 120 米**；城墙（基地）在 `y ≈ 2.5`；敌人从上方（世界 +Z）向下推进。
- 相机是**正交俯视**（`CameraRig` 固定 `Euler(90,0,0)`），屏幕「上」= 世界 +Z = 逻辑 +Y。
- 建造槽位是一排 6 个圆盘：直径 **3.4 / 2.9 米**，间距 10 米，`y = 12`。

### 1.2 朝向约定（最容易踩坑）

| 对象 | 代码行为 | 建模要求 |
| --- | --- | --- |
| 防御塔炮塔 | `TowerView.Tick` 每帧写 `turret.localRotation`，`yaw = 90° − AimAngle` | 炮管沿 **+Z**，炮塔旋转轴为本地 Y 轴，枢轴在底座中心正上方 |
| 追踪投射物（火箭） | `Quaternion.LookRotation(delta)` | 弹头朝 **+Z**，轴心在中心 |
| 抛射投射物（迫击炮） | 只改位置、**不改旋转** | 做成**旋转对称**外形，避免看出朝向错误 |
| 敌人 | 只改位置与 `body.localScale`，不写旋转 | 不要依赖模型自身朝向；圆/方/环等俯视可读的造型最稳 |

> 炮塔枢轴高度：生成模板是 `Turret.localPosition = (0, 0.3, 0)`。自建模型请把炮管旋转枢轴放在 `y ≈ 0.3` 的塔体顶部，否则转向时会「甩」出去。

### 1.3 尺寸标尺（照这个做就不会失控）

| 对象 | 关键尺寸 | 备注 |
| --- | --- | --- |
| 防御塔底座 | 直径 **1.4 m**、高 **0.2 m** | 生成模板；可略放大，但别超过槽位圆盘 2.9 m |
| 炮管 | 长 **1.2 m**、截面约 0.18 m | 炮口不要超过底座外沿太多 |
| 塔总高 | 建议 **≤ 1.5 m** | 正交俯视时过高会遮挡后方敌人 |
| 小型敌人 | 碰撞半径 0.5 m → 显示直径 **1 m** | 数量最多（单波数百） |
| 中型敌人 | 半径 1.0 m → 直径 **2 m** | |
| 大型敌人 | 半径 **7.5 m** → 显示直径 **15 m** | 是「母体/堡垒」尺度，不要做成人类大小 |
| 投射物占位 | 球体直径 **0.6 m** | 视觉大小与逻辑 `BulletRadius` 解耦 |
| 无人机单机标记 | 约 **0.28 × 0.12 × 0.42 m** | 8~15 架绕圈展示 |
| 避雷针 | 高约 **1.8 m**，顶端球 0.32 m | 由 `Rod.prefab` 提供 |
| 地面区域 | **直径 1 的圆盘**，运行时按半径 ×2 缩放 | 不要直接做成最终大小 |

## 2. 零基础：环境与工具准备

这一节假设你**从未打开过 Blender**。照着做即可，不需要先学完整套三维软件。

### 2.1 需要安装什么

| 软件 | 用途 | 版本 / 获取 |
| --- | --- | --- |
| **Blender** | 建模、UV、导出 FBX | 4.2 LTS 或 4.x 稳定版，官网 blender.org 免费下载 |
| **Unity（团结引擎）** | 打开本工程、导入 FBX、制作 Prefab | 2022.3.62f1；用 Unity Hub 安装并添加 `d:\MyWork` |
| **Krita / Photoshop**（可选） | 贴图绘制 | Krita 免费；本工程前期可只用纯色，不必贴图 |
| **PureRef**（可选） | 参考图拼贴 | 免费；把塔/敌人参考图钉在屏幕角落 |
| **Unity Hub** | 管理 Unity 版本与工程 | 官网免费 |

不需要：3ds Max、Maya、ZBrush、Substance、Marvelous Designer。本工程是**低模 + 纯色 + 黑描边**，Blender 基础功能足够。

### 2.2 硬件与操作习惯

- **必须有三键鼠标**：Blender 的中键旋转视图、Shift+中键平移是高频操作；只有触控板会非常痛苦。
- 建议双屏：一边 Blender，一边 Unity Game 视图；没有双屏就频繁 Alt+Tab。
- 数位板不是必需品；贴图阶段再考虑。
- **保存习惯**：Blender 里每完成一个部件按一次 `Ctrl+S`；工程目录里按 `_v01 / _v02` 另存，避免覆盖后无法回退。
- **命名习惯**：文件名全小写、下划线分隔、无空格无中文（例如 `tower_rocket.fbx`、`enemy_foundry.fbx`），减少 Unity 与命令行问题。
- **备份**：`.blend` 源文件放 `Assets/Art/Models/Source`，导出的 FBX 放 `Assets/Art/Models/Export`，贴图放 `Assets/Art/Models/Textures`。单个 FBX 建议 < 2 MB，贴图 ≤ 512。

### 2.3 Blender 首次配置（照着勾）

打开 Blender → `Edit → Preferences`：

| 页面 | 设置 | 说明 |
| --- | --- | --- |
| Interface → Translation | Language 选「简体中文」（可选） | 不习惯英文界面时使用 |
| Input | 勾选 `Emulate 3 Button Mouse` | 没有中键时用 Alt+左键代替 |
| Input | 勾选 `Emulate Numpad` | 笔记本没有小键盘时用主键盘数字 |
| Save & Load | `Auto Save Timer` 设为 2 分钟 | 崩溃可恢复 |
| System | `Undo Steps` 设为 64 | 建模容错 |
| Viewport | 单位 Metric、Unit Scale 1.0 | 与 Unity 的 1 米对齐 |

新建工程时选 **General**，得到默认 Cube / Camera / Light。可以全选删掉，只保留空场景。

**场景单位检查**：右侧 `Scene Properties → Units` → `Metric`、`Meters`、`Unit Scale = 1.0`。

### 2.4 Blender 与 Unity 的分工

| 环节 | 在哪做 | 说明 |
| --- | --- | --- |
| 形状、比例、UV | Blender | 导出 FBX |
| 材质、颜色、透明度 | Unity | 统一 `Unlit/Color` 或 `Unlit/Texture`；Blender 里的材质只作占位 |
| 组件、挂点、Prefab | Unity | 根节点挂 `TowerView` / `EnemyView` / `ProjectileView` |
| 资源映射 | Unity | `AssetCatalog.asset` 按 id / mechanic 绑定 |

不要在 Blender 里做 Unity 的组件、脚本、碰撞体；也不要把灯光、相机导出。

### 2.5 建议的学习路线（按本工程需求裁剪）

1. **第 1 天**：视图导航 + 移动/旋转/缩放 + 做一个方块塔（30 分钟就能完成）。
2. **第 2 天**：圆柱、挤出、倒角、镜像，做完整的一座机枪塔。
3. **第 3 天**：低模敌人（球 + 锥 + 箱体组合），理解原点与尺寸。
4. **第 4 天**：导出 FBX、导入 Unity、替换占位网格、接 AssetCatalog。
5. **后续**：UV 与贴图、简单动画、粒子与尾迹。

不要从雕刻、高模、角色绑定开始；本工程 90% 的资产是**几何体拼装 + 纯色**。

## 3. Blender 够用操作

只列本工程会用到的功能。掌握这一节即可完成全部塔与敌人占位模型。

### 3.1 视图导航

| 操作 | 快捷键 |
| --- | --- |
| 旋转视角 | 中键拖动 |
| 平移视角 | `Shift + 中键拖动` |
| 缩放 | 滚轮 |
| 前 / 右 / 顶视图 | 小键盘 `1` / `3` / `7` |
| 后 / 左 / 底视图 | `Ctrl + 小键盘 1 / 3 / 7` |
| 正交 / 透视切换 | 小键盘 `5` |
| 聚焦选中物体 | 小键盘 `.`（或 `View → Frame Selected`） |
| 显示全场景 | `Home` |
| 孤立显示选中物体 | `/`（小键盘斜杠） |
| 实体 / 线框切换 | `Z` 然后选 Solid / Wireframe |
| 全选 / 取消 | `A` / `Alt+A` |

### 3.2 物体模式：移动、旋转、缩放

| 操作 | 快捷键 / 说明 |
| --- | --- |
| 移动 / 旋转 / 缩放 | `G` / `R` / `S`，然后按 `X` `Y` `Z` 锁定轴，或直接输入数字 |
| 精确移动 | 按 `G` `Z` 输入 `0.3` 回车 |
| 添加物体 | `Shift + A` → Mesh → Cube / Cylinder / UV Sphere |
| 删除 | `X` |
| 复制 | `Shift + D`；`Alt + D` 为关联复制（共享网格数据） |
| 合并 | 选中多个 → `Ctrl + J` |
| 分离 | 编辑模式选中面 → `P` |
| 应用变换 | `Ctrl + A` → `All Transforms`（导出前必须做） |
| 设置原点 | `Object → Set Origin → Origin to Geometry`（敌人/投射物）或 `Origin to 3D Cursor`（塔） |
| 查看尺寸/位置 | 右侧 `N` 面板 → Item → Dimensions / Location |

> 原点操作是本工程最关键的步骤之一：塔的原点在底座中心贴地，敌人/投射物的原点在几何中心。先摆好物体，再设原点，最后 Apply。

### 3.3 编辑模式（Tab）常用工具

| 工具 | 快捷键 | 用途 |
| --- | --- | --- |
| 点 / 线 / 面选择 | `1` / `2` / `3` | |
| 挤出 | `E` | 拉出炮管、机匣、装甲板 |
| 内插 | `I` | 在面上内缩出一圈结构线 |
| 倒角 | `Ctrl + B`，滚轮加段数 | 让边缘有轻微高光，线稿风格建议 1~2 段、宽度 0.01~0.02 |
| 环切 | `Ctrl + R`，滚轮加线 | 在圆柱/管体上加结构线 |
| 切割 | `K` | 手动切线 |
| 补面 | `F` | 封口 |
| 合并顶点 | `M` | 清理缝隙 |
| 重算法线 | `Ctrl + Shift + N` | 模型发黑/发暗时先做这个 |
| 平滑 / 平直着色 | `Object → Shade Smooth / Shade Flat` | 线稿硬边模型用 Flat 或 Auto Smooth |

**修改器（Modifier）建议**：

- `Mirror`：左右对称的塔体、装甲板。
- `Array`：蜂巢发射器、栅格、重复铆钉。
- `Solidify`：薄板加厚，避免单面片。
- `Bevel`：小倒角，低模也能有干净高光。
- `Boolean`：慎用，容易产生 n-gon 与破面；能用拼装解决就不要布尔。

### 3.4 从零做一个机枪塔（10 步示例）

1. `Shift + C` 把 3D 游标归零。
2. `Shift + A → Mesh → Cylinder`，在左下角面板设 `Vertices = 16`、`Radius = 0.7`、`Depth = 0.2`，得到底座。
3. 底座位置 `Z = 0.1`（贴地），`Ctrl + A` 应用缩放。
4. `Shift + A → Mesh → Cube`，缩放成 `0.38 × 0.32 × 0.38`，放在 `Z = 0.5`，作为机匣。
5. `Shift + A → Mesh → Cube`，缩放成 `0.18 × 0.18 × 1.2`，沿炮口方向前移 0.6，作为炮管。
6. 选中炮管与机匣 → `Ctrl + J` 合并，重命名为 `Turret`。
7. 把 `Turret` 的原点设到塔体中心正上方（`Z = 0.3`），这样旋转时不会甩出去。
8. 选中底座与炮塔 → 新建空物体 `Tower_machine_gun` 作为父级，或直接保留两个对象在导出后于 Unity 里组层级。
9. 在 Unity 里确认炮管朝 **+Z**；若朝反了，回 Blender 绕 Z 轴旋转 180° 并 `Ctrl + A` 应用。
10. 导出 FBX（见 3.7），进 Unity 替换占位网格。

> 炮管朝向不要求在 Blender 里绝对正确，**最终以 Unity 场景里炮管指向 +Z 为准**；不对就转模型，不要在 Prefab 根节点上加旋转。

### 3.5 原点与单位（重点中的重点）

| 对象 | 原点位置 | 做法 |
| --- | --- | --- |
| 防御塔 | 底座中心、地面高度 | `Shift + C` 归零游标 → 选中模型 → `Object → Set Origin → Origin to 3D Cursor` |
| 敌人 | 几何中心 | `Object → Set Origin → Origin to Geometry` |
| 投射物 | 几何中心 | 同上 |

- 导出前必须 `Ctrl + A → All Transforms`，否则 Unity 里会出现奇怪的缩放/旋转。
- 在 `N` 面板核对尺寸：塔底座直径应为 1.4、敌人小型应为 1×1×1 左右、投射物约 0.6。
- 不要让模型位于离世界原点很远的位置；Unity 里根节点应在 `(0,0,0)`。

### 3.6 低模与法线

- 目标是**俯视可读的剪影**，不是细节量。塔 300~800 三角面，小型敌人 50~150。
- 优先用方块、圆柱、球体拼装；避免 n-gon（超过 4 条边的面），导出后容易破面。
- 边缘用 `Ctrl+B` 做 1~2 段小倒角，Unity 的 Unlit 材质不会显示高光，但倒角能形成一条细亮边，线稿风格更清楚。
- 法线：`Ctrl+Shift+N` 重算朝外；如果模型在 Unity 里看起来「空」或发黑，先检查法线。
- 线稿风格建议 `Shade Flat`；想要圆滑的球体再用 `Shade Smooth`。

### 3.7 导出 FBX（本工程参数）

1. 只选中你要导出的物体（不要选相机、灯光、参考图）。
2. `File → Export → FBX (.fbx)`。
3. 关键设置：

| 设置 | 值 |
| --- | --- |
| `Selected Objects` | 勾选 |
| `Apply Scalings` | `FBX Units Scale`（或 `All Local`，两者都不要出现 100×） |
| `Forward` / `Up` | 以 Unity 里炮管朝 +Z 为准；不对就回 Blender 转模型 |
| `Apply Unit` | 勾选 |
| `Apply Transform` | 勾选 |
| `Mesh → Smoothing` | `Face`（线稿硬边）或 `Off` |
| `Armature` / `Animation` | 不需要就关闭 |
| `Cameras` / `Lights` | 关闭 |

4. 导出到 `Assets/Art/Models/Export/<name>.fbx`，Unity 会自动导入。
5. 在 Unity 里按第 4.3 节检查导入设置。

### 3.8 UV 与贴图（可选，先跳过也不影响）

- 纯色模型不需要 UV；如果要做线稿贴图：
  1. 编辑模式 `A` 全选 → `U → Smart UV Project`；
  2. 新建 Image Texture 节点，套一张棋盘格检查拉伸；
  3. 导出前 `U → Pack Islands`，留 4 px 边距；
  4. 贴图 512×512，白底黑线或纯色块。
- 本工程当前全部用纯色材质，贴图属于后续可选升级。

### 3.9 新手常见错误（Blender 侧）

1. **导出整个场景**：把相机、灯光、参考图都带进 Unity。只选模型，勾 `Selected Objects`。
2. **忘记 Apply**：Unity 里出现 0.01 或 100 倍缩放。导出前 `Ctrl+A → All Transforms`。
3. **原点在地图外**：Unity 里塔跑到奇怪位置。先 `Shift+C` 归零，再设原点。
4. **比例差 100 倍**：单位不是米，或导出缩放选错。N 面板核对尺寸。
5. **炮管朝向错误**：在 Unity 里看 +Z；不对就转模型后重新导出。
6. **模型发黑/透明**：法线翻转或单面片。`Ctrl+Shift+N`，薄板加 `Solidify`。
7. **文件名带空格/中文**：Unity 与命令行容易出问题，统一小写下划线。
8. **一个文件里放多个塔**：资产混乱。一个塔一个 FBX。
9. **边数过多的圆柱**：64 边圆柱对俯视剪影没有帮助，16~24 边足够。
10. **布尔后破面**：尽量用拼装和倒角替代布尔。

## 4. 资产管线与导入设置

### 4.1 推荐目录（与 `Unity接入说明.md` 第 5 节一致）

```
Assets/Art/Towers/<tower_id>.prefab        机枪塔 machine_gun / laser / mortar / rocket / tesla / drone_hangar
Assets/Art/Towers/<tower_id>_icon.png      塔图标（256×256）
Assets/Art/Enemies/<enemy_id>.prefab       13 种敌人
Assets/Art/Projectiles/<mechanic>.prefab   投射物，可为空
Assets/Art/Models/Source/...               .blend 源文件
Assets/Art/Models/Export/...               导出的 FBX
Assets/Art/Models/Textures/...             贴图
```

### 4.2 Blender → FBX

| 项目 | 建议值 |
| --- | --- |
| 单位 | Metric，1.0 比例；导出前 `Apply Scale/Rotation` |
| 轴 | 最终在 Unity 里确认 **+Z 朝前**；Blender 里可先朝 +Y，导出后不对就转 180° |
| 原点 | 塔：底座中心贴地；敌人 / 投射物：几何中心 |
| 变换 | 全部 Apply；Prefab 根节点保持 `Position=0, Rotation=0, Scale=1` |
| 网格 | 三角面/四边形，合并同材质；不要导出摄像机 / 灯光 / 空物体 |
| 动画 | 如需动画，导出为独立 AnimationClip，不要把根位移烘进去 |

### 4.3 Unity 导入设置（Model 页）

| 设置 | 值 | 原因 |
| --- | --- | --- |
| Scale Factor | **1** | 1 单位 = 1 米 |
| Convert Units | 开（按导出单位） | 防止 100× |
| Import BlendShapes | 关（除非要用） | 省内存 |
| Import Cameras / Lights | 关 | 避免场景多出对象 |
| Generate Colliders | **关** | 严禁挡住点击拾取 |
| Mesh Compression | Off / Low | 低模压缩容易破面 |
| Read/Write | 关 | 运行时不需要改网格 |
| Optimize Mesh | 开 | |
| Weld Vertices | 开（硬边模型关闭） | 线稿风格慎用，可能吃掉棱线 |

### 4.4 材质

- 工程使用**内置渲染管线**，场景里**没有灯光**，材质统一 `Unlit/Color`（见 `ProjectSetupWizard.CreateMaterialAsset`）。
- 需要纹理细节时用 `Unlit/Texture`；需要透明时用 Unlit 的透明变体，**不要用 Standard**。
- 所有同色物件**共享一个材质**；需要逐实例变色时由代码用 `MaterialPropertyBlock`（参考 `AreaFieldView`）。
- 贴图：**256 或 512**，sRGB 开，Mipmap 按需；线稿贴图用白底黑线，别做灰底。
- 若是半透明区域（燃烧 / 低温）：保持**单层、无重叠**，避免透明排序闪烁。

### 4.5 弹道表现（已实现，建模时要知道）

- **实弹（机枪）**：从塔外 **1 米**处开始，沿判定直线在 **3 帧**内延伸到射程端点；之后保持约 **8 帧**，再整体渐隐。轨迹**起点先淡出、弹着点最后消失**，颜色纯黑。
- **激光（矩形光束）**：与判定矩形**同宽同长**，白色半透明填充 + **浅灰色**细描边；完整显示约 **8 帧**后整体渐隐。
- 实现位置：`BattleViewRoot.UpdateTracers`（表现层），数据来自 `TowerAgent.ShotTraces` / `BattleSimulation.ShotFired`。
- **持续照射型激光**（聚焦 / 扫荡透镜）：开始照射后会锁定并持续结算，即使目标死亡也会把剩余照射时间打完；期间光束会跟随当前目标，找不到目标时保持最后方向。
- 这意味着：**不要给机枪/激光建模弹丸**，它们的弹道由代码绘制；只有迫击炮、火箭、电弧、无人机等需要投射物模型。

## 5. 防御塔建模

### 5.1 必需的层级结构

生成模板（可直接复制改网格，最省事）：

```
Tower_<id>                        ← TowerView 组件挂在根上
├─ Base                           圆柱：直径 1.4、高 0.2，y=0.1
├─ Turret                         空节点，localPosition=(0,0.3,0)
│  ├─ Barrel                      炮管：沿 +Z，长度约 1.2
│  └─ Breech                      炮尾 / 机匣
├─ LevelRoot                      6 个等级标记（Pip0..Pip5）
└─ Selected                       选中高亮圆环（默认隐藏）
```

`TowerView` 的 Inspector 必须保留三个引用：`turret`、`levelRoot`、`selectedMark`。

### 5.2 通用建模建议

- **俯视优先**：相机是正上方，造型要靠**外轮廓**区分，不要靠侧面细节。
- **白底黑线**：塔体浅灰 / 白色，结构线用黑色描边或深色缝隙；强调色只用在炮口、能量核心。
- **低矮**：总高建议 0.6~1.4 m；高塔会遮住后方敌群。
- **炮管可读**：炮管从正上方要能看出「哪边是枪口」，否则转向反馈消失。
- **等级标记**：6 个 pip 由代码控制显隐（Lv2 起逐级点亮），位置在半径 0.85 的圆上；自建模型不要覆盖这块区域。
- **选中环**：由一个独立的扁平圆柱显示，不要做进塔体材质里。

### 5.3 六塔的造型语言（建议）

| 塔 | 轮廓关键词 | 建模建议 | Lv4 / Lv7 形态提示 |
| --- | --- | --- | --- |
| 机枪塔 `machine_gun` | 低矮、方正、双管 | 沙袋/掩体式底座 + 一根主炮管 | Lv4 旋转机炮=多管束；电磁反器材=细长导轨 + 线圈 |
| 激光塔 `laser` | 立式、透镜、干净 | 竖直发射器 + 大圆透镜，白光/浅紫自发光 | 聚焦透镜=单大镜；扫荡透镜=三束小镜 |
| 迫击炮 `mortar` | 圆坑、短粗、仰角 | 圆形炮坑 + 55°~70° 短炮管；底座做**旋转对称** | 空爆=多管蜂巢；破片=粗口喇叭；阵列炮=三联 |
| 火箭塔 `rocket` | 箱式、管口、工业感 | 方形发射箱 + 4 个管口 | 蜂窝=8 孔蜂巢；发射井=单盖板 + 粗井口 |
| 电弧塔 `tesla` | 线圈、环、能量 | 立柱 + 2~3 层线圈环，顶部球体 | 高压电容=大电容罐；球形闪电=悬空球体 |
| 无人机库 `drone_hangar` | 平台、机库、雷达 | 停机坪 + 雷达天线 + 机库门 | 飓风=单机重炮；移动工厂=可移动平台；大舰巨炮=加装舰炮 |

> 迫击炮 `noTurn = true`：逻辑上炮塔会**瞬间对准**目标。把底座做成圆形、炮管放在中轴，可以让这次「瞬移」不明显。

### 5.4 炮塔动画的边界

- **不要**在 AnimationClip 里 K `Turret.localRotation`：`TowerView` 每帧覆盖。
- 后坐力：在 `Turret` 下再挂一个 `Recoil` 子节点，动画只动 `Recoil.localPosition`（+Z 方向小幅回弹）。
- 炮口闪光 / 弹壳：挂在 `Barrel` 末端空节点 `Muzzle` 上；目前代码未读取该点，属于预留挂点。
- 激光 / 电弧的光束由运行时绘制，**不需要建模光束**；只做发射器本体。
- 塔开火音效由 `AssetCatalog.TowerArt.fireSfx` 提供，不依赖模型。

## 6. 投射物建模

### 6.1 层级与朝向

```
Projectile_<mechanic>
├─ 主体网格（+Z 为飞行方向，轴心居中）
└─（可选）Trail / Glow 子节点
```

- 根节点挂 `ProjectileView`（已有池化，按 `mechanic` 取用，未使用的实例会被隐藏）。
- **追踪弹**（火箭系）会用 `LookRotation` 转向，模型必须 +Z 朝前。
- **抛射弹**（迫击炮系）不写旋转，模型请做成**旋转对称**（炮弹、罐体），否则会看到「躺着飞」。
- 视觉大小建议 0.4~0.8 m；`BulletRadius` 不驱动视觉缩放。
- **机枪 / 激光没有投射物模型**：弹道由 `BattleViewRoot` 绘制，见 4.5。

### 6.2 按机制的可选模型

| 机制 / 弹种 | 建议外形 |
| --- | --- |
| 火箭 / 导弹（`split_warhead` / `missile_silo`） | 弹体 + 尾翼；发射井弹可做成粗短钻地弹 |
| 空爆子母弹 / 蜂窝（`cluster` / `swarm`） | 母弹 + 抛撒子弹（子弹共用小方块，由运行时生成，不必逐个建模） |
| 电浆 / 球形闪电 / 漏电 | 自发光球体 + 轻微缩放动画 |
| 凝固汽油弹 / 液氮弹（`napalm` / `cryo`） | 罐体 + 颜色区分（橙 / 冰蓝） |
| 雷电滚滚（`rolling_thunder`） | 球体，径向对称 |
| 无人机自爆 | 不使用投射物模型，走 `Vfx_Default.prefab` |

> 地面区域（`AreaField.prefab`）、避雷针（`Rod.prefab`）、落点空心圆都是独立预制体，不要塞进投射物里。

## 7. 敌人建模（建议先做大型与中型）

### 7.1 层级与缩放规则

```
Enemy_<id>
├─ Body         ← 主体网格（必须能被直径 1 的单位球包住，轴心在中心）
├─ HpBar        ← 血条（代码按比例改 localScale.x）
└─ StatusRoot   ← 状态图标挂点（燃烧 / 低温 / 碎甲）
```

`EnemyView` 每帧执行：

- `body.localScale = 半径 × 2`（小型 1、中型 2、大型 15）；
- `body.localPosition.y = 半径`（把模型抬到半球高度）。

因此**模型主体的轴心必须在几何中心**。如果轴心在脚底，模型会整体下沉一半；如果主体超过单位球，缩放后会明显穿模。

### 7.2 体型与识别

| 体型 | 显示直径 | 造型语言 | 备注 |
| --- | --- | --- | --- |
| 小型 | 1 m | 圆 / 三角 / 小方块，单一轮廓 | 同屏最多，优先低面数 |
| 中型 | 2 m | 六边形 / 装甲方块 / 前盾 | 需要与小型有明显轮廓差 |
| 大型 | 15 m | 环形 / 工厂 / 堡垒，中心留空或大块装甲 | 俯视占比大，是视觉焦点 |

13 种敌人的差异化建议：

- **小型**：`worker` 圆点、`hunter` 三角、`composite` 双圆组合、`shooter` 圆 + 短炮管。
- **中型**：`skirmisher` 菱形、`assault` 尖头方块、`firepower` 厚炮塔、`bulwark` 重甲方箱、`shield` 正面大盾。
- **大型**：`foundry` 圆形铸造环、`furnace` 方形熔炉、`magnet` 磁环、`ironwall` 厚重装甲板。四者靠**外轮廓**区分，不要只靠颜色。

### 7.3 动画与性能边界

- **不要**给 `Body` 做缩放呼吸动画（每帧被覆盖）；需要呼吸感就动 `Body` 的子节点。
- 不要用蒙皮网格，500 只同屏会拖垮；用 Transform 动画或顶点着色器做轻微起伏。
- 血条与状态图标由代码控制，别把它们烘进模型。
- 敌人不需要 Collider；索敌与伤害全部走逻辑坐标。

## 8. 接入流程（不改代码）

1. **复制生成模板**：先运行 `Tools → 防线指挥 → 一键生成演示场景`，在 `Assets/Unity/Generated/Prefabs` 里复制 `Tower_<id>` / `Enemy_<id>` / `Projectile` 作为底稿，保留所有挂点与组件引用。
2. **替换网格**：把自己的 FBX 拖进 `Body` / `Barrel` / `Turret` 下，删除占位 Primitive 的 MeshFilter/MeshRenderer（或直接替换 mesh）。
3. **换材质**：新建 `Unlit/Color` 或 `Unlit/Texture` 材质，颜色对齐现有白底黑线风格。
4. **对齐枢轴与朝向**：在 Scene 里把相机切到 Top 视图，确认炮管朝 +Z、模型贴地、敌人居中。
5. **保存到 `Assets/Art/...`**：按第 4.1 节目录命名，生成 Prefab Variant 或独立 Prefab。
6. **挂进 AssetCatalog**：`Assets/Unity/Generated/Data/AssetCatalog.asset` → 找到对应 id → 填 `prefab`（塔/敌人）或 `mechanic`（投射物）。
7. **运行验证**：见第 11 节清单。

> 不要直接修改 `Assets/Unity/Generated/**` 里的模板并期待长期有效：一键生成会重建它们。正式资源放 `Assets/Art/**`，通过 AssetCatalog 覆盖。

## 10. 防踩坑清单（按出现频率排序）

1. **材质全黑**：用了 Standard/Lit。改成 `Unlit/Color` 或 `Unlit/Texture`。
2. **塔巨大 / 极小**：FBX 单位不是米，或 Scale Factor 不是 1。检查导入设置并 Apply Scale。
3. **塔悬空**：根节点原点不在底座贴地面。把原点移到底座中心 y=0。
4. **炮管反向**：模型前向不是 +Z。旋转网格或在 Blender 里改朝向，别在 Prefab 根上加 180° 旋转。
5. **炮管转向时飞出**：Turret 枢轴不在旋转轴上。把 Turret 空节点放在塔体中心正上方（y≈0.3）。
6. **敌人下沉 / 浮空**：`Body` 轴心不在几何中心。`EnemyView` 会把轴心抬到半径高度。
7. **大型敌人穿模**：模型没有收进直径 1 的单位球，缩放 15 倍后爆掉。
8. **点了空位没反应**：模型自带 Collider 挡住了槽位射线。删除所有 Collider。
9. **动画不生效**：动画 K 了 Turret 旋转 / Body 缩放，被每帧逻辑覆盖。改为动子节点。
10. **塔看起来在「抖」**：把选中环 / 等级标记做进了主体网格，被材质或动画影响。保持它们独立。
11. **贴图糊 / 锯齿**：贴图低于 256 或 Mipmap 设置错误；线稿建议 512、关 Mipmap 或用 Point 过滤。
12. **半透明闪面**：多个透明面重叠。合并成单层，或用 Alpha Cutout。
13. **模型发灰发脏**：用了带光照的材质但没有灯光。Unlit + 纯色。
14. **投射物躺着飞**：给迫击炮弹做了明显「上下面」，而抛射弹不旋转。改成旋转对称。
15. **火箭倒飞**：弹头朝 −Z。确认 `LookRotation` 的正向。
16. **换资源后占位没消失**：AssetCatalog 的 id 拼错（大小写、下划线）。id 必须与 `towers.json` / `enemies.json` / `mechanic` 完全一致。
17. **重新一键生成后资源丢失**：资源放在了 `Assets/Unity/Generated`。正式资源必须放 `Assets/Art`。
18. **同屏掉帧**：每个敌人独立材质 / 高面数 / 蒙皮。共享材质 + 低模 + 关阴影。
19. **Prefab 根有非 1 缩放**：会与 `TowerView` / `EnemyView` 的运行时缩放叠加。根节点保持 `Scale=1`。
20. **模型把 UI 挡住**：塔太高或选中环太大。控制总高 ≤ 1.5 m。
21. **给机枪 / 激光做了弹丸模型**：它们的弹道由代码绘制，模型不会显示。参见 4.5。
22. **模型里带灯光/相机**：导入后场景变亮或出现多余对象。导出时关闭。

| **激光束发光** | 激光开火 | 在现有白底黑边矩形上叠加一层更宽的半透明发光层 | 需要 additive 材质；内置管线想有泛光需 Post Processing Stack v2 |
| **爆炸发光** | 投射物落点 / 区域生成 | 自发光球体 + 快速缩放，配合现有 `SpawnAoeRing` | `BattleVfxSink` 按 `mechanic` 挂预制体 |
| **穿透粒子** | 子弹/光束命中并穿透敌人 | 在命中点喷出 3~5 个短寿命粒子，方向沿弹道 | 需要新增逐命中事件（当前机枪 `ApplyBeam` 没有事件） |
| **过量伤害击碎** | 单次伤害远超剩余生命 | 按 overkill 比例触发碎片/爆散粒子，大型敌人额外碎块 | 需要击杀事件携带 `overkill` 数值 |
| **受击闪红 / 闪白** | 敌人每次受伤 | 用 `MaterialPropertyBlock` 改颜色 0.05~0.08 s；大型敌人可加轮廓闪 | 共享材质不能用 `renderer.material.color`，否则会实例化材质 |
| **炮管制退与摇晃** | 每次开火 | `Recoil` 子节点沿 −Z 回弹；长间隔武器（导弹井 / 氢弹）加低频摆动 | 开火事件；不要动 `Turret.localRotation` |
| **导弹 / 火箭尾焰与烟雾** | 投射物飞行期间 | `TrailRenderer` + 粒子，尾焰沿 −Z 拖出；命中后停止发射 | 投射物池化复用时要 `Clear()` 并重启粒子 |

建议实现顺序（投入产出比）：

1. **受击闪红/闪白**（反馈最直接，改动小）
2. **枪口火光**（射击手感）
3. **炮管制退与摇晃**（重武器存在感）
4. **导弹/火箭尾焰**（飞行可读性）
5. **激光发光 / 爆炸发光**（需要后处理或叠加材质）
6. **穿透粒子**（需要命中事件）
7. **过量伤害击碎**（需要击杀事件与碎片资源）

共性依赖：一个**统一的表现层事件通道**（开火 / 命中 / 击杀 / 过量伤害）。当前只有 `ShotFired`（机枪/激光）与 `CombatWorld.Impacted`（投射物落点），后续新增效果时建议扩展这两个事件，而不是在逻辑层里直接生成特效。
